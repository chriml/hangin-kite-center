# Windguru forecast implementation, 2026-09-13

Status: Implemented locally, verified, awaiting owner review; not deployed

The owner requested Windguru forecasts after the optional map work. The Boracay spot guide and kite-size guide now contain the official Hangin/Bulabog GFS forecast, loaded only after a visitor action. A direct Windguru link, provider disclosure and WhatsApp paths remain static. Forecast values are not copied into the site or calculator. See [ADR 0003](../decisions/0003-optional-windguru-forecast.md) for sources and the accepted runtime boundary.
