# Hangin identity assets

Approved by the owner on 2026-09-08. Website incorporation and local SVG tracing were explicitly authorized in the same conversation.

## Source and preparation

The modern logo was created with built-in ImageGen from Hangin's existing public wordmark. Primary reference: [Hangin Kite Center & Resort on Facebook](https://www.facebook.com/HanginKiteCenterAndResort/), [profile photo](https://www.facebook.com/photo/?fbid=968769408605504&set=a.406014451547672), inspected 2026-09-08. The design uses the existing name and accent; no third-party sponsor marks are included.

The [approved PNG](../../docs/brand/hangin-logo-approved.png) was converted locally with [Vision Cortex VTracer](https://github.com/visioncortex/vtracer), Python package 0.6.15, on 2026-09-08. Color regions were traced as outlines and assigned the site's coral, ocean and sun colors. Cream background and raster texture were discarded; the approved letter contours and spacing were retained. This was a one-time authoring tool, not a website dependency. SVGs contain paths only, with no embedded bitmap, font, script or external resource.
