# Instructor organization logos

The website owner requested IKO and VDWS logos beside the existing About-page instructor statement and explicitly confirmed permission to display both on 2026-09-13. That confirmation authorizes this website use; it does not establish an IKO-affiliated center, VDWS member school, or individual staff credentials.

[IKO's terms](https://www.ikointl.com/gutenberg/367099) require prior consent for republication; the owner confirmation above was obtained before these files were added to public assets. Both marks link to their official organizations. Neither is offered under an open-content license. Public credits are collected at `/legal/`.

Both SVGs were inspected for scripts, foreignObject elements, event handlers and external references; none were present. The IKO artwork is originally white; VDWS is displayed in white through CSS. Both retain original proportions on an ocean background. No runtime external image request is used.
