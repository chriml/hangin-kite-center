# Hangin Kite Center Website

Initial SEO-focused website setup for Hangin Kite Center using a no-brainer stack:

- Next.js (App Router) + React + TypeScript
- Tailwind CSS
- Built-in SEO routes (`robots.txt`, `sitemap.xml`, `manifest.webmanifest`)
- Structured data (JSON-LD) on the homepage

## Scripts

```bash
npm run dev
npm run lint
npm run build
npm run start
```
